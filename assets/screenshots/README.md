# Screenshot provenance

These four browser captures show the plugin's actual React components rendered
with the DSH 0.2.1-rc.2 UI runtime and theme styles in an isolated offline fixture.
The surrounding shell is a preview harness, not a capture of a signed-in account.

All conversation titles, messages, reasoning, search results, filenames and
credential hints are synthetic. The route image was drawn specifically for this
demo; it contains no photograph, real location or itinerary. No real account
credentials, conversations, file URLs or personal filesystem paths were loaded.

Screenshots were checked visually before inclusion. Browser chrome and the OS
desktop are outside the capture. The visible demo label intentionally remains.
Captures contain no screenshot metadata chunks beyond PNG image data.
